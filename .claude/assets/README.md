# Assets (bring your own)

The starter ships no persona or brand imagery. Skills look for:

- `brand/<persona>/reference-hero.png`: identity reference for a persona (thumbnails, clones, QA)
- `brand/<persona>/screenshots/`: app screenshots used as B-roll
- `brand/<brand>/app-icon.png` and `brand/<brand>/bg-stock/`: pro-tips deck icon + stock backgrounds
- `fonts/`: extra display fonts (the carousel overlay falls back to system fonts)

Only add images you own or have rights to use.
